# Trip fixtures

Real `POST /api/trips` responses (`TripOut`), made from the demo dataset. Use them to build the itinerary page before the live API is connected.

- `trip_ankle.json`: the ankle-injury persona. 3 days, with many places in "Places we skipped".
- `trip_deaf.json`: the Deaf, non-speaking persona. 3 days.

The facts in these files come from the demo dataset. Their `source` is `demo_data`. Show the `source_label` text ("demo data, not verified") on the badges, not the raw `source`.
